Is a process whereby a fraction of the output signal is sensed (Vf) and compared with the input (Vin), generating a very small feedback error term, thereby making the output an accurate replica of the input

There are 2 kinds of feedback: negative and positive. If the sensed feedback voltage has the same phase with the input, then it's negative; otherwise, it is positive.

- Negative feedback allows high precision signal processing. 
- Positive feedback makes it possible to build oscillators

Benefits of negative feedback:
* Gain desensitization: Closed loop gain is much less sensitive to device parameters than the open loop gain.
* Controls the input/output impedance: raise or lower the input and output impedances by selection of an appropriate feedback topology.
* Increases the amplifier bandwidth
* Reduces noise by minimizing the contribution (to output) of unwanted electric signals 
* Reduces nonlinear distorsion
