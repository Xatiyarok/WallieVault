It is a current drawn by the input terminals. It is a leakage current that sources or sinks at both input terminals. 
- Depending on the type of input transistor, the bias current can flow in or out of the input terminals.

IOS - Input current offset: difference between the input bias current at both terminals. Typically is an order of magnitude less than bias current.
- Can range from nA to pA. 
- MOSFET have smaller bias currents than BJT types
- Bipolar ~nA
- MOSFET/JFET ~pA
