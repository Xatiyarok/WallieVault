This electronic device has 3 differents input modes:
- inverting mode: the non-inverting input of the op is grounded. Output signal is 180 out of phase with the input.
- non-inverting: inverting input is grounded. output signal is in phase with the input
- differential mode: signals are applied to both inputs.  These signals have to be 180 out of phase and the output is going to be in phase with the non-inverting signal. If input are both in phase, there should be no output.
